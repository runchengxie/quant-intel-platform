# Web Dashboard Data-Source Research Note

[Chinese version](web-dashboard.md)

> This is an early research note about the data required to reproduce an external market overview terminal, current gaps, and possible provider costs. Prices and recommendations below are a dated snapshot, not current purchasing advice. The project dashboard command is `dm dashboard`; it writes `out/web_dashboard.html` and `out/web_dashboard_payload.json`.

## Executive summary

1. The largest gaps identified were next-twelve-month price/earnings (NTM P/E) and forward earnings per share (EPS). The value-oriented starting option in this 2026-07-02 assessment was FMP Premium at USD 79/month, approximately CNY 536/month, or about USD 59/month (CNY 401/month) on an annualized plan. Higher-quality alternatives such as FactSet Estimates and S&P Capital IQ Estimates required a quote.
2. The next priority was point-in-time S&P 500 constituents, so breadth could be calculated from the actual constituents on each historical date. The note listed EODHD Fundamentals Data Feed at USD 59.99/month (about CNY 407) or All-in-One at USD 99.99/month (about CNY 679) as lower-cost options, and S&P Global Index Data as a quote-based option.
3. A daily job can gradually populate `market_state_panel.csv`. For useful backtests at launch, the note recommended backfilling at least three to five years of VIX, breadth, valuation, and forward-return data.

## Findings

This note inventories the data needed by the market overview terminal at <https://www.lucasgou.cloud/>, what this project had reproduced at the time, the remaining gaps, and indicative provider costs.

The project had a static dashboard generated by `dm dashboard`, with outputs `out/web_dashboard.html` and `out/web_dashboard_payload.json`. At that time the page read this repository's ETL outputs, snapshots, and an optional state panel. It did not call the target website's API.

The assessment grouped the findings into three points:

1. Market sentiment and cross-market prices had a display-ready foundation: VIX, VVIX, Cboe Put/Call, AAII, SPY/QQQ, gold, DXY, and the 10-year Treasury yield were represented.
2. Valuation and constituent breadth were the principal gaps. SPX/NDX NTM P/E, forward EPS, valuation percentiles, and point-in-time constituent breadth generally required commercial data or a manually maintained panel.
3. For a course reproduction, start with proxy indicators, a fixed-constituent CSV, low-cost price APIs, and a manually maintained valuation panel. A formal research workflow could later evaluate FactSet, Bloomberg, LSEG, S&P Capital IQ, or Cboe DataShop.

The cost estimates were dated 2026-07-02 and used an approximate USD/CNY rate of 6.79. Recheck provider prices, academic and personal/commercial licensing, exchange permissions, content storage, and redistribution terms before purchasing.

## Remaining gaps

| Gap | Impact | Suggested direction in the original note |
| --- | --- | --- |
| Raw CNN Fear & Greed values | Only `fear_greed_proxy` can be shown | Keep the local proxy and add SPX momentum, actual breadth, credit spreads, and safe-haven demand |
| SPX/NDX constituent breadth | Cannot reproduce 20/50/200-day constituent-breadth trends | Start with a fixed-constituent CSV and low-cost daily prices; later obtain point-in-time constituents |
| SPX/NDX NTM P/E and forward EPS | Core valuation, return attribution, and implied P/E remain proxies | Start with a manually maintained `valuation_panel.csv`; obtain consensus estimates for a formal version |
| Valuation percentiles and historical returns | Too few state-backtest observations to reproduce nearest-state statistics | Build a history panel and add 5/30/90/252-day forward returns |
| Macro-calendar license | Trading Economics returned HTTP 401; the calendar needed a fallback | Consider FMP or EODHD for lower cost; evaluate Trading Economics for wider coverage |
| News body and media assets | Open Hub can show only headlines and source chains | Add deduplication IDs and entity labels first; connect bodies/media only after licensing review |
| HSI prices | Stooq returned insufficient data, leaving the Hong Kong index unavailable | Consider FMP, Twelve Data, a Hong Kong ETF, or exchange-authorized data |
| Strategy lab | No natural-language rule parsing or backtest result | Build rule templates first, then consider LLM parsing and a backtest sandbox |

## Suggested sequence from the original note

1. Persist VIX, VVIX, Put/Call, AAII, SPY/QQQ, 10Y yield, and topic valuations to the state panel.
2. Add SPX/NDX 20/50/200-day breadth using fixed-constituent CSVs and low-cost daily prices. Label the results `proxy`.
3. Add `valuation_panel.csv` for manual or licensed SPX/NDX NTM P/E, forward EPS, and valuation percentiles.
4. Add SPY/QQQ historical prices and 5/30/90/252-day forward returns for nearest-state statistics.
5. Replace the HSI source to reduce dependence on Stooq for the Hong Kong module.
6. Use FMP, EODHD, or public RSS for macro events until Trading Economics credentials and plan access are confirmed.
7. Add `event_id`, entity labels, and deduplication rules before storing licensed news bodies or media.
8. Defer the strategy lab to phase two. Start with fixed rule templates, then consider natural-language parsing.

## Dashboard generation

Generate the static dashboard with:

```bash
uv run dm dashboard
```

| Output file | Purpose |
| --- | --- |
| `out/web_dashboard.html` | Static page for local viewing or static-site publication |
| `out/web_dashboard_payload.json` | Structured data for tests, diagnosis, and downstream use |

Optional state-panel commands:

```bash
uv run dm state-panel --period 10y --timeout 30
uv run dm dashboard --state-panel path/to/market_state_panel.csv
```

`dm state-panel` attempts to build `out/market_state_panel.csv` from FRED, Cboe VIX/VVIX, Cboe Put/Call, and yfinance. To calculate SPX/NDX constituent breadth, pass `--include-breadth --breadth-mode sample`. This is a slow operation; write to a separate CSV first and review its quality.

Without `--state-panel`, `dm dashboard` checks `MARKET_STATE_PANEL` and then `out/market_state_panel.csv`. If neither provides an explicit panel, the page derives one proxy state from Cboe/FRED VIX, Cboe Put/Call, AAII, SPY/QQQ, topic valuation, and the 10-year Treasury yield. It is labeled `derived:free-source-proxy`, represents one day only, and does not replace a historical state panel.

Suggested state-panel fields:

| Field | Purpose |
| --- | --- |
| `date` | Observation date |
| `own_risk_appetite_score` | Locally constructed risk-appetite score |
| `rsp_spy_participation_proxy` | Market-participation proxy |
| `valuation_rate_gap_proxy` | Valuation/rate-gap proxy |
| `spx_above_50d_pct`, `ndx_above_50d_pct` | SPX/NDX 50-day breadth |
| `spy_high`, `qqq_high`, `spy_52w_high`, `qqq_52w_high` | SPY/QQQ highs |
| `spx_ntm_pe`, `ndx_ntm_pe`, `spy_ntm_pe`, `qqq_ntm_pe` | Index or ETF valuation proxies |
| `spx_ntm_pe_percentile`, `ndx_ntm_pe_percentile` | Valuation percentiles |
| `vix`, `spy_close`, `sp500_close`, `ten_year_yield`, `hy_oas` | Latest state indicators |
| `spy_forward_return_fwd_90d`, `spy_forward_return_fwd_252d`, `spy_forward_return_fwd_1260d`, `spy_forward_return_fwd_2520d` | Subsequent returns |

## Coverage labels

The page uses four status labels:

| Status | Meaning |
| --- | --- |
| `available` | Native project data is available for direct display |
| `proxy` | A local or constructed proxy is used; the page must explain its methodology |
| `simulated` | Example, simulated, or local fallback data is used |
| `missing` | An input file, required field, valid credential, or permission is missing |

When news content is not licensed, store only its headline, source, and URL. Mark valuation, breadth, Fear & Greed, and other proxy-derived fields as `proxy`.
