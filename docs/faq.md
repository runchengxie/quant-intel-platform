# 常见问题

## 第一次应该看什么

先看[五分钟开始](getting-started.md)，再看[核心概念](concepts.md)。需要具体操作时，直接查看[常见任务](how-to/run-daily-report.md)。

## 没有 API 凭据可以运行吗

可以运行安装、帮助、离线测试、文档构建和部分降级流程。真实数据抓取需要对应服务商的凭据和权限。

## 本地运行会发送消息吗

默认不会。消息目标由部署环境提供，没有目标时只生成本地文件。生产投递由 `quant-intel-deploy` 管理。

## 为什么看不到 A 股完整报告

A 股完整报告需要研究仓和数据仓提供正式输入。缺少这些输入时，平台会展示已有快照，或明确标记缺失状态。

## `DATA_PLATFORM_ROOT` 和 `MDP_DIR` 有什么区别

`DATA_PLATFORM_ROOT` 指向数据目录，`MDP_DIR` 指向数据仓源码目录。前者用于读取数据，后者用于调用数据仓的公开命令。

## 如何判断一次运行是否成功

查看 `out/` 中的状态文件、生成时间和日期，再检查是否有对应的 receipt。不要只看进程退出码。

## 可以把生产配置提交到这个仓库吗

不可以。生产凭据、客户目标、定时任务、日志、回执和真实快照应放在私有部署环境。详细边界见[Public 仓库边界](public-release/public-boundary.md)。
