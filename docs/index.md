# Quant Market Intel

[中文页面](index.zh-CN.md)

Quant Market Intel is the public framework for market intelligence, reporting, dashboards, and published research contracts. Start with the [five-minute setup](getting-started.md), then read the [core concepts](concepts.md) and [system architecture](architecture.md).

Production credentials, scheduled jobs, real delivery targets, and runtime state belong to the private deployment repository. This public repository provides reusable code, versioned contracts, offline checks, and reviewed public pages.

The public site reports facts with source dates, evidence links, and explicit data-quality boundaries. Research algorithms and strategy artifacts remain owned by `quant-research`, `quant-platform`, `strategy-pipeline`, and the other owner repositories documented in the boundary contracts.
