# 报告写作规范

[English page](report-writing-style.en.md)

研究请求、简短摘要和有来源依据的市场解读都应使用自然、清楚的中文。完整报告和限定章节的写作路径遵循同一套要求。人工来源审核员改写已批准的来源时也应遵守这些要求。

核对发布日期、事件日期和适用条件。判断信息在报告截点是否仍然适用，只使用该截点之前可获得的证据。未知日期继续标为未知，不用后续事件解释更早的判断。只有在有助于读者理解时才在正文中写日期，不要逐句重复元数据。

直接表达。删去重复的否定句、套式转折、晦涩词语、翻译腔、不必要的中英混杂和没有证据支持的结论。避免无意义的总结段。使用中文标点，少用不必要的引号、粗体、分号和破折号。输出格式允许时保留有意义的来源名称和行内代码。提交前再通读一遍，检查这些问题。

经过来源核对的改写可以这样写：

> 嘉信理财10月1日的盘前观察主要关注科技股表现和高位美债收益率。

来源的发布时间和盘中阶段仍应保留在元数据中。删掉重复免责声明，不代表可以把这句话写成收盘解读。必要的不确定性、缺失数据说明、证据引用、JSON 字段和数值契约都必须保留。

个人飞书评论应简短且不写日期。已经核实的输入仍保留日期，评论不能使用之后出现的信息或外部材料。该输出不允许使用 Markdown。写作规范变更会使评论生成缓存失效，但不会影响已成功投递的回执。

这些提示和编辑检查不能保证模型一定写出符合人工质量的文本。离线测试验证提示词接线和缓存边界，不验证线上模型的实际写作质量。已批准的历史报告不会自动重写。运行时变更需要单独发布。
