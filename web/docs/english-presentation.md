# English presentation boundaries

English routes translate complete reviewed terms and explanatory clauses. They do
not run successive single-character substitutions over source text. Unknown names
and source passages remain intact; a missing translation is preferable to a
fabricated or fragmented one. Company names without a reviewed English alias retain
their original spelling and stock code. This is presentation localization, not
model-generated translation or a change to the canonical reports.

Numbers, observation dates, public chart hashes, source URLs, Markdown link
destinations and SVG attributes remain unchanged. Interactive charts localize labels
and controls only; raw units still determine axis grouping, and the score axis
retains its 0–100 bounds and loss-risk semantics.

Regression coverage includes the September 30 mixed-language examples, pure and
mixed-script names, overlapping metric labels, degraded states, quoted SVG attribute
values and links. New data or prose variants need complete-term/phrase coverage;
do not add catch-all character replacements to hide translation gaps.
