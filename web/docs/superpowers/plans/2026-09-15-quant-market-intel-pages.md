## 归档和构建约束

报告按 ID 合并，简评按晨晚报来源组合合并。全量数据写入仓库外的归档目录，核对完整后再缩小公开窗口。报告修订的不可覆盖记录由后来加入的导入器负责保存。

公开窗口按五个不同的报告日期计算。构建时检查简评来源是否存在、报告类型是否匹配，以及简评日期是否与晨报目标日期一致。未被索引引用的 Markdown 不进入 Pages 产物。

构建输出使用专用目录，每次重新创建。完整私有归档与构建产物分别保存。

## 页面约束

- 日期筛选只提供公开窗口内的日期。
- 简评与其来源日期绑定，某日缺少简评时展示相应空状态。
- 报告类型筛选、正文展开和 Markdown 原文入口继续可用。
- 报告及模型正文使用文本节点渲染。

## 验证记录

原计划要求覆盖归档合并、重复输入、五日期裁剪、简评来源校验，以及构建产物排除未引用 Markdown。页面检查覆盖默认视图、日期切换、暂无简评、晨晚报筛选和文本渲染。

这些约束已进入现有 Python 与 Node.js 测试。维护时以 [README 的检查命令](../../../README.md#检查与维护)运行当前测试集，测试数量和最新运行结果记录在当次变更中。
